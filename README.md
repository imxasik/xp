# XP Telecom

বাংলাদেশি অপারেটর অফার, ড্রাইভ প্যাক ও রিচার্জ স্টোর। PHP + JSON (ডাটাবেজ নেই)।

## চালু

```bash
php -S 0.0.0.0:8080
```

- স্টোর: `/`
- অ্যাডমিন: `/admin.php` — `admin` / `admin123`

ডাটা ফাইল: `data/*.json`

## কাস্টম গেটওয়ে (XPPay)

তৃতীয় পক্ষ নেই। বিকাশ/নগদ/রকেট/উপায়/ইউক্যাশ/ব্যাংক মার্চেন্ট নম্বর অ্যাডমিন থেকে সেট করুন।

অটো মিল:

`POST /api/index.php?action=gateway_auto`

```json
{"secret":"xp-secret-change-me","trx":"ABC123XYZ","amount":100,"paycode":"BK123456"}
```

ওয়ালেট পেমেন্ট ইনস্ট্যান্ট। TrxID ইউনিক ও ফরম্যাট ঠিক থাকলে অটো-অ্যাপ্রুভ চালু করা যায়।
