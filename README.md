# XP Telecom

বাংলাদেশি অপারেটর অফার, ড্রাইভ প্যাক ও রিচার্জ স্টোর। PHP + JSON (ডাটাবেজ নেই)।

## চালু

```bash
php -S 0.0.0.0:8080
```

- স্টোর: `/`
- অ্যাডমিন: `/admin.php` — `admin` / `admin123`

ডাটা ফাইল: `data/*.json`

## কাস্টম গেটওয়ে (XPPay)

তৃতীয় পক্ষ নেই। বিকাশ/নগদ/রকেট/উপায়/ইউক্যাশ/ব্যাংক মার্চেন্ট নম্বর অ্যাডমিন থেকে সেট করুন।

অটো মিল:

`POST /api/index.php?action=gateway_auto`

```json
{"secret":"xp-secret-change-me","trx":"ABC123XYZ","amount":100,"paycode":"BK123456"}
```

ওয়ালেট পেমেন্ট ইনস্ট্যান্ট। TrxID ইউনিক ও ফরম্যাট ঠিক থাকলে অটো-অ্যাপ্রুভ চালু করা যায়।

## নোটিফিকেশন ও সার্ভিস সময়

- 🔔 স্টোর ও অ্যাডমিন হেডারে বেল আইকন; নতুন অর্ডার/পেমেন্ট/হিট/রিফান্ড — সব ইভেন্টে নোটিফিকেশন (`data/notifications.json`)।
- অ্যাডমিন **নোটিফিকেশন** ট্যাব থেকে সবাইকে বা নির্দিষ্ট ইউজারকে ঘোষণা পাঠানো যায়।
- **সেটিংস → সার্ভিস সময়**: ড্রাইভ অফার হিটের সময় (ডিফল্ট সকাল ৮টা–রাত ১০টা), নামাজের বিরতি ও গড় হিট সময়। ইউজার স্টোরে, অর্ডারের সময় ও অর্ডার ট্র্যাকিংয়ে এই তথ্য দেখে।
- ড্রাইভ (ম্যানুয়াল হিট) অর্ডার কখনো অটো-সম্পন্ন হয় না; অ্যাডমিন **✅ হিট হয়েছে** চাপলে ইউজার নোটিফিকেশন পায়। **❌ ফেল** করলে ওয়ালেট-পেইড অর্ডারের টাকা অটো ফেরত যায়।
- অ্যাডমিন অর্ডার কার্ডে নম্বর ট্যাপ = কপি, **📄 সব তথ্য** = পুরো অর্ডার এক ক্লিকে কপি (হাউস থেকে হিট করার জন্য)।

API (ইউজার): `notifications` (`mark_read`), `service` · (অ্যাডমিন): `admin_notifications`, `admin_poll`, `admin_broadcast`, `admin_delete_user`, `admin_user_status`
